# Cypewriter

一个极简、沉浸式的网页打字空间。打开主页，只有一个终端式闪烁光标；开始输入后，文字出现在缓慢流动的彩色背景之上。

## 特点

- **只有文字与光标**：没有标题、按钮、计数器或品牌标识。
- **终端式光标**：方块光标跟随输入位置、换行与选区。
- **动态流体背景**：通过 WebGL 实时生成连续流动的色彩，基础色相约三分钟完成一次完整循环。
- **鼠标互动**：指针附近的流体产生柔和的扰动。
- **中文输入支持**：使用原生文本输入区域，支持输入法、粘贴、撤销与移动端键盘。
- **适配与降级**：适配手机与桌面；尊重减少动态效果设置，WebGL 不可用时保留静态渐变。

## 使用

直接用浏览器打开 `dist/index.html`，点击文字区域即可输入。文字仅保留在当前页面内存中，刷新或关闭页面后不会保存，也不会上传。

## 项目结构

```text
dist/
  index.html    页面结构
  style.css     排版与光标样式
  app.js        输入交互与流体背景
```

无需安装依赖或构建工具。部署时将 `dist` 作为静态网站目录即可。
